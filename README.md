# Coralize

<p align="center">
  <img src="resources/coralize.png" alt="Coralize" width="96" height="96">
</p>

给每个工作区，一抹中国色。

打开活动栏中的 **Coralize**，点击色卡即可换色。顶部斜纹横条按当前分类随机换色，并定位选中色卡。也可输入 HEX，回车应用。

全部颜色按朱、金、青、蓝、墨五列独立滚动；“明 / 暗”提供跨色系的明亮、深色精选配色。

右上角设置中预览并选择应用区域：标题栏、活动栏、状态栏。需要清空配色时，运行命令“Coralize：清空工作区配色”。

换色会覆盖整个工作区的 `workbench.colorCustomizations`，不备份；用户级设置不变。请勿同时使用其他工作区配色插件。
